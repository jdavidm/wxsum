wxsum v6.0

A fast, Mata-powered Stata command for transforming remote-sensing weather data into seasonal and exposure-window statistics.

New in Version 6.0: Inline compiled Mata engine for 10x–100x performance gains, unit-specific exposure windows (e.g., household-level planting dates), panel-ready long format by default, extreme heat metrics, and the official data-preparation companion command wxprep.

Installation

Install directly from GitHub into Stata:

net install wxsum, from("https://raw.githubusercontent.com/jdavidm/wxsum/main/") replace

Overview & Capabilities

wxsum processes daily precipitation and temperature series to compute agricultural degree days, heat and dry spell durations, threshold counts, and rolling historical anomalies:

  • Dual Analytical Modes: Calendar Window Mode for standard cropping seasons and Unit-Specific Window Mode for individual-level exposure periods.
  • Long Format Output by Default: Automatically outputs one observation per unit-year (shape(long)) ready for panel regressions.
  • Extreme Heat Physiology: Captures extreme heat using heat_threshold(#), calculating heatdays, pct_heatdays, leading/mid/trailing heat spells, and Killing Degree Days (kdd).
  • Historical Anomalies: Generates deviations (dev_) and standardized z-scores (z_) against rolling windows (lr_years(#)) or fixed reference baselines (baseline(y1 y2)).
  • Companion Prep Command: Use wxprep for reshaping long weather data to wide (towide), standardizing variables (rename), and extracting long panels (tolong).

Syntax

Calendar Window Mode

wxsum stub, type(rain|temp) ini_month(month) fin_month(month) [options]

Unit-Specific Exposure Window Mode

wxsum stub, type(rain|temp) start(varname) end(varname) [options]
wxsum stub, type(rain|temp) event_date(varname) days(#) [lag(#) options]

Companion Prep Command (wxprep)

wxprep towide varname, id(varlist) date(varname) stub(string) [options]
wxprep rename varlist, stub(string) firstdate(string)
wxprep tolong stub, id(varlist) [generate(varname) date(varname) clear]

Quick Examples

* 1. Seasonal rainfall summary (long output)
use rain.dta, clear
wxsum rf_, type(rain) ini_month(05) fin_month(10) ini_day(15) fin_day(15) keep(hhid)

* 2. Cross-year temperature degree days and heat spells
use temp.dta, clear
wxsum tmp_, type(temp) ini_month(11) fin_month(02) gdd_lo(8) gdd_hi(32) heat_threshold(32) keep(hhid)

* 3. Household-specific planting date window (90 days)
wxsum rf_, type(rain) event_date(plant_date) days(90) lr_years(5) keep(hhid plant_date)
