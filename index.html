wxsum

A command for processing temperature and precipitation data. Version 6.0.

Overview

wxsum turns daily weather data into statistics for a window of days: a season that repeats every year (a calendar window), or a window that differs by observation, such as a farm's growing season or the months before a birth (a unit-specific window). Calendar windows may cross the end of the year; they are labeled with the year in which they start. The companion command wxprep converts long daily data, or wide data with other variable names, into the layout wxsum needs.

Installation

net install wxsum, from("https://raw.githubusercontent.com/jdavidm/wxsum/main/") replace
net get wxsum, from("https://raw.githubusercontent.com/jdavidm/wxsum/main/")

Stata 15 or later. Wide daily data have one variable per day, so Stata/SE and Stata/MP need set maxvar above the default of 5,000 for long histories.

Data Requirements

  1. The data are "wide": each location is a row and each daily reading is a numeric variable.
  2. The daily variables are named with a common prefix followed by yyyymmdd, such as rf_19790515. Calendar days without a variable are treated as missing days.
  3. Long data (one row per location-day) can be converted with wxprep towide; wide data with other names with wxprep rename.

Syntax

wxsum stub, type(rain|temp) ini_month(#) fin_month(#) [ini_day(#) fin_day(#) options]
wxsum stub, type(rain|temp) start(varname) end(varname) [partial options]
wxsum stub, type(rain|temp) event_date(varname) days(#) [lag(#) partial options]

wxprep towide varname, id(varlist) date(varname) stub(string) [daily(mean|sum|min|max) ...]
wxprep rename varlist, stub(string) firstdate(date) [convert(varlist)]
wxprep tolong stub, id(varlist) [generate(name) date(name) convert(varlist) clear save(filename [, replace])]

Options

  • type(rain|temp) - required. Other daily series (humidity, wind) use temp.
  • ini_month(), fin_month(), ini_day(), fin_day() - calendar window.
  • start(), end(), or event_date() with days() and lag() - unit-specific window; partial uses the available days when a window runs past the data.
  • rain_threshold(#) - rainy day if rain >= #. Default 1.
  • gdd_lo(#), gdd_hi(#) - growing degree day bounds (required for temp).
  • heat_threshold(#) - heat day if temp >= #; also the killing degree day base (required for temp). kdd_base(#) sets a different KDD base.
  • gdd_bin(), gdd_binlo(), gdd_binhi() - seasonal GDD categories (gddcat).
  • tmp_bin(), tmp_binlo(), tmp_binhi() - equal-width temperature bins; cuts(numlist) - bins at your own cutpoints.
  • lr_years(#) - rolling reference period (default 10); baseline(# #) - fixed reference period; ref_min(#) - reference years required.
  • minobs(#) - observed days required for a window's statistics.
  • shape(long|wide) - default long; outstub() - prefix for output names; keep(varlist); save(filename [, replace]).

Output

For each window: nobs, mean, median, var, sd, skew; for rain total, mean_mo, raindays, norain, pct_raindays, and dry spells dry_start, dry, dry_end; for temperature max, gdd, kdd, heatdays, pct_heatdays, and heat spells heat_start, heat, heat_end; deviations (dev_) and z-scores (z_) relative to the reference period; and optional GDD categories and bins. wxsum stores results in r(), including a missing-data summary by window, and leaves the data unchanged if anything fails.

Examples

Rainfall, 15 May to 15 October

clear all
set maxvar 20000
use rain.dta
wxsum rf_, type(rain) ini_month(5) ini_day(15) fin_month(10) fin_day(15) keep(hhid) save(rain_season, replace)
return list

Growing and killing degree days and heat spells

use temp.dta, clear
wxsum tmp_, type(temp) ini_month(5) ini_day(15) fin_month(10) fin_day(15) gdd_lo(10) gdd_hi(30) heat_threshold(29) keep(hhid)

Temperature bins and GDD categories

use temp.dta, clear
wxsum tmp_, type(temp) ini_month(5) ini_day(15) fin_month(10) fin_day(15) gdd_lo(10) gdd_hi(30) heat_threshold(29) tmp_bin(8) tmp_binlo(20) tmp_binhi(32) gdd_bin(100) gdd_binlo(2000) gdd_binhi(2400) keep(hhid)

Growing seasons that differ by household and year (example data)

use hh_panel.dta, clear
merge m:1 hhid using rain.dta, nogenerate
wxsum rf_, type(rain) start(plant) end(harvest) keep(hhid year plant harvest yield)

Hourly temperature to daily maxima (example data)

use weather_hourly.dta, clear
generate tempc = t2m - 273.15
wxprep towide tempc, id(hhid) date(time) stub(tmax_) daily(max) clear
wxsum tmax_, type(temp) ini_month(3) fin_month(5) gdd_lo(10) gdd_hi(30) heat_threshold(38) keep(hhid)

The example do-file wxsum_examples.do and its log run all examples in the article. The example datasets hh_panel.dta, births.dta, and weather_hourly.dta are simulated (make_example_data.do creates them); they illustrate the commands and are not observed data.
